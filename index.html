Isravel Backup

Isravel Backup is a private tool used only by Isravel Department Store, Thondamuthur, Tamil Nadu, India.

It keeps an off-site copy of the store's own data backups in the store owner's Google Drive. The backups are encrypted on the store's server before they are uploaded, so neither Google nor anyone else can read them without the owner's backup password.

The app is not offered to the public and does not have other users.
